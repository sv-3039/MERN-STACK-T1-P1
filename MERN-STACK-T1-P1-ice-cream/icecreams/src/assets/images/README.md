# 📸 Scoop & Co. — Your Images Go Here

Drop your own images into these folders and the website will **automatically use them** — no code changes needed!

> ⚙️ **How it works:** the app checks these folders first. If a matching file exists, it is used. If not, the current internet (Unsplash) image keeps showing, so nothing ever looks broken.

## ✨ Quick Start
1. Pick the image you want to replace.
2. Find its name in the tables above.
3. Copy your file into the matching folder with that exact name (lowercase, spaces → `-`).
4. Refresh the site — done! 🎉

## 💡 Tips
- Recommended size: **at least 600×600 px** for products, **800×800 px** for hero.
- If you want to temporarily go back to the internet image, just delete your local file.
- The home page `hero.png` at `src/assets/hero.png` is also used — you can replace that file directly too.
