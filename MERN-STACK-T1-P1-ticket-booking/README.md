# MernStack_Team

## Movie Ticket Booking

This project is a React + Vite based Movie Ticket Booking application developed as part of the MernStack Team collaborative repository.

### Features

* Responsive user interface
* Movie listings
* Hero section
* Navigation bar
* Movie cards
* Footer
* Fast development using Vite
* Component-based architecture with React

### Tech Stack

* React
* Vite
* JavaScript
* HTML5
* CSS3

### Getting Started

1. Clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open your browser and visit:

```
http://localhost:5173
```
