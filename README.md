# 🌸 Fragrance World

Fragrance World is an online perfume shopping website built using the MERN stack. It provides users with a simple and user-friendly interface to explore, search, and purchase a wide range of fragrances.

## 🚀 Features

- Home page with featured perfumes
- Product listing
- Product details
- Search functionality
- Shopping cart
- User authentication
- Responsive design

## 🛠️ Technologies Used

- MongoDB
- Express.js
- React.js
- Node.js
- HTML5
- CSS3
- JavaScript

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the backend:
   ```bash
   npm start
   ```

4. Start the frontend:
   ```bash
   npm start
   ```
